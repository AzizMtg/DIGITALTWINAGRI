## 8. Les liens entre les volets

La consigne demande de « transversaliser ». Exemples :
- le prix (marketing) est la base du chiffre d'affaires (finance) ;
- le mode d'achat des chambres (juridique : commande publique) change le cycle de vente (marketing)
  et le délai d'encaissement (finance) ;
- l'assurance et la formation des télépilotes (juridique) sont des coûts (finance) ;
- la propriété des données (juridique, éthique) est un argument de confiance (marketing).
